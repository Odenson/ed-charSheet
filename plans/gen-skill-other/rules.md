# Rules brief: gen-skill-other

## R1 — Knowledge/Artisan: Novice, default attribute, player-named + GM-approved
- **Status:** FAQ-HIT
- **Ruling:** Both are Novice, Strain 0. Knowledge default attribute PER; Artisan default CHA. Player names the subject / invents the Artisan skill, subject to GM approval.
- **Sources:** RULES-FAQ Q043, Q044; PG text-RB-players-guide.txt:7184-7201 (p.198), :6996-7002 (p.193), :6984-6999
- **Decision:** none
- **Used by:** T4, T5

## R2 — Tier and Rank-1 cost
- **Status:** ANSWERED
- **Ruling:** Each skill prints its own tier. Novice Rank 1 = 200 LP, Journeyman 300 LP; new skill takes 1 week, fee Rank x 10 sp (10 sp at Rank 1). Only Novice skills are buyable with creation skill points.
- **Sources:** RULES-FAQ Q045, Q043; PG :17076, :17086-17102 (pp.450-451), :2354-2360 (p.70)
- **Decision:** none
- **Used by:** T5

## R3 — Skill Step = Rank + attribute Step
- **Status:** ANSWERED
- **Ruling:** Step is Rank + the Step of the attribute named in the skill description.
- **Sources:** RULES-FAQ Q045; manual/text-player-guide-skill-concepts.txt:41-46 (p.184)
- **Decision:** none
- **Used by:** T1, T5

## R4 — Custom General skills (tier, attribute)
- **Status:** NOT-COVERED
- **Ruling:** The book lets players invent only Knowledge and Artisan skills. Nothing governs a new General skill's tier or attribute.
- **Sources:** RULES-FAQ Q045; PG :7000-7002, :7184-7201
- **Decision:** Owner house rule, 2026-11-22: a custom General skill gets an owner-chosen attribute and a selectable tier (Novice or Journeyman). Knowledge/Artisan stay Novice with an editable default attribute. Creating custom skills is gated by a homebrew rule, enabled for now.
- **Used by:** T3, T5

## R5 — Knowledge example subjects as catalog entries
- **Status:** NOT-COVERED (descriptions); ANSWERED (attribute, tier, strain)
- **Ruling:** The book prints 17 example Knowledge subjects but no per-subject text. All are instances of generic Knowledge: Rank + Perception, Standard, Strain 0, Novice.
- **Sources:** RULES-FAQ Q046; PG text-RB-players-guide.txt:7184-7201, :7211-7230
- **Decision:** Owner, 2026-11-23: add seven (Barsaive History, Creature Lore, Discipline Lore, Legends and Heroes, Racial Lore, Scourge History, Trade Routes) as full catalog entries with app-authored descriptions (not book text). Supersedes the R11 closed knowledge list of two.
- **Used by:** catalog (post-build change)
