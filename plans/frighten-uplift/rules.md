# Rules brief: Frighten uplift (frighten-uplift)

## R1 — Frighten talent stat block
- **Status:** FAQ-HIT
- **Ruling:** Step Rank+WIL, Standard action, Strain 0, Skill Use No, tested vs target's Mystic Defense. App data matches (Novice tier from app data).
- **Sources:** RULES-FAQ Q017, Q018, Q049(9); text-RB-players-guide.txt:5251-5260; text-talents-players.txt:336-339
- **Decision:** none
- **Used by:** T2

## R2 — Penalty, duration, re-use
- **Status:** ANSWERED (APP-DIFFERS on duration)
- **Ruling:** On success the target takes -2 to ALL tests per success, for a number of rounds equal to the adept's Frighten Rank. No re-use rule of its own; general Q049(10) applies (greater effect wins). App data has `duration: "special"`; book says Rank rounds — feature follows the book.
- **Sources:** RULES-FAQ Q050, Q049(10); text-RB-players-guide.txt:5254-5259, 4088-4095
- **Decision:** 2026-11-24 owner: Rank rounds, one entry per cast (stacking is a non-goal).
- **Used by:** T1, T2

## R3 — End-test
- **Status:** ANSWERED
- **Ruling:** Each round the target may make a Willpower test vs the adept's Frighten Step (fixed difficulty); on success the fear and the talent end. Timing within the round not stated.
- **Sources:** text-RB-players-guide.txt:5258-5259; RULES-FAQ Q050
- **Decision:** 2026-11-24 owner: reminder text on the entry (with the Frighten step) + existing X; no in-app roll.
- **Used by:** T2

## R4 — Exclusions
- **Status:** ANSWERED
- **Ruling:** Fear-immune targets are unaffected; no range/LOS/language requirement. Not modelled beyond note text.
- **Sources:** text-RB-players-guide.txt:5260; RULES-FAQ Q050
- **Decision:** none
- **Used by:** T2

## R5 — Death's Head / Evil Eye
- **Status:** ANSWERED
- **Ruling:** Death's Head makes Frighten Simple (already modelled); its extra-thread +2 is a test bonus. Evil Eye (+1 success to Frighten) is a different spell. Neither modelled here.
- **Sources:** RULES-FAQ Q050, Q017; text-RB-players-guide.txt:12137-12153, 12395-12405
- **Decision:** none (out of scope)
- **Used by:** none
