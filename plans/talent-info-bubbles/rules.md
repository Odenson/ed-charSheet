# Rules brief: Talent info bubbles (talent-info-bubbles)

No Earthdawn rule is computed or asserted by this feature. It only displays the
talent text already recorded in `rules/talents.json` (summary, action,
attribute, Strain, tier, versus, notes, effect summaries) for talents a picker
already lists; which talents are eligible, their prices and gating are
unchanged and out of scope. Rules sweep done at design time: nothing to send to
the rule-agent.
