# Rules brief: Unarmed Combat missing short effect (unarmed-short-effect)

## R1 — Step, action, Strain
- **Status:** FAQ-HIT
- **Ruling:** Step = Rank + Dexterity; Standard action; Strain 0.
- **Sources:** RULES-FAQ Q025 (1); text-talents-players.txt:691-694; text-RB-players-guide.txt:6383-6390 (p. 177)
- **Decision:** none
- **Used by:** T1

## R2 — Skill Use
- **Status:** FAQ-HIT
- **Ruling:** Usable as a skill, at Novice tier ("Skill Use: Yes (Novice)").
- **Sources:** RULES-FAQ Q025 (1); text-talents-players.txt:693; p. 177
- **Decision:** none
- **Used by:** T1

## R3 — Talent tier / Warrior placement
- **Status:** ANSWERED
- **Ruling:** The talent's own entry has no fixed tier; tier follows the Circle it is learned at (Q001: 1–4 Novice). In core lists it appears only among Novice Talent Options (Warrior, Sky Raider, Swordmaster), so `tier: "Novice"` matches how the book offers it. It is not a Warrior Circle 1 Discipline Talent.
- **Sources:** RULES-FAQ Q025 (7), Q001; text-discipline-players.txt:432, 434-436, 295, 329; text-RB-players-guide.txt:3945-3948 (p. 85), 18400-18419 (pp. 457-458)
- **Decision:** none
- **Used by:** T1

## R4 — Attack target
- **Status:** FAQ-HIT
- **Ruling:** Attack test vs the target's Physical Defense.
- **Sources:** RULES-FAQ Q025 (2); text-talents-players.txt:694; text-RB-players-guide.txt:14727-14741 (pp. 391-392)
- **Decision:** none
- **Used by:** T1

## R5 — Hit and Damage
- **Status:** FAQ-HIT
- **Ruling:** On success the attack hits; the Damage test uses Strength Step only unless noted otherwise. No unarmed-specific extra-success bonus (general +2 Damage Steps per extra success vs Physical Defense applies). Attached weapons still count as weapons (owner house rule Q026: their Damage Step adds to Strength Step).
- **Sources:** RULES-FAQ Q025 (1, 3), Q026; text-talents-players.txt:694; text-RB-players-guide.txt:922-936 (p. 34), 14199-14229 (pp. 378-379)
- **Decision:** none new (Q026 house rule pre-existing)
- **Used by:** T1

## R6 — Karma
- **Status:** FAQ-HIT
- **Ruling:** No Karma line in the talent's own entry; general rule allows 1 Karma on the talent (Attack) test when used as a talent, not as a skill. Karma on Damage needs a Discipline grant.
- **Sources:** RULES-FAQ Q025 (6); text-RB-players-guide.txt:4111-4144 (pp. 120-121)
- **Decision:** none
- **Used by:** T1 (summary text only; no new effect)
