# Rules brief: Taxonomy on action type (taxonomy-on-action-type)

## R1 — Action types
- **Status:** ANSWERED
- **Ruling:** Five types: Standard (one/round), Simple (normally unlimited, usually independent), Free (unlimited, usually not independent), Sustained, NA. A talent requires its printed Action every time it is used.
- **Sources:** RULES-FAQ Q018; text-RB-players-guide.txt:4194-4233 (p. 122-123); 13988-14082 (p. 373-375)
- **Decision:** none
- **Used by:** T1, T3

## R2 — Ordering between action types
- **Status:** NOT-COVERED
- **Ruling:** Books print no hierarchy or substitution rule between action types.
- **Sources:** Q018
- **Decision:** Owner house rule 2026-10-03: when several active effects set different actions on the same talent, the fastest wins (Free > Simple > Standard). Valid effect values: Free, Simple, Standard. An effect `set`s the action (override, not "must be faster than base").
- **Used by:** T1, T2

## R3 — Frighten base action and Death's Head change
- **Status:** FAQ-HIT
- **Ruling:** Frighten is Standard, Strain 0. Death's Head: "he may use the Frighten talent as a Simple action for the duration of the spell" (Rank+5 rounds), every use during the duration. Still once per round.
- **Sources:** Q017; text-RB-players-guide.txt:5251-5253, 12147-12149 (p. 323)
- **Decision:** none
- **Used by:** T4

## R4 — Other action-changing abilities (future users of the type)
- **Status:** ANSWERED
- **Ruling:** Beguiling Blade (Companion): Conceal Object "as a Simple action, instead of a Standard action" (companions-guide:1735-1741). Swift Link (Deeper Secrets knack): Thought Link as a Simple action (13724-13728). Not in scope to migrate.
- **Sources:** Q018
- **Decision:** none
- **Used by:** T1 (non-goal note)
