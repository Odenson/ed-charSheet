# Rules brief: Start a new Discipline (start-new-discipline)
Ledger: docs/RULES-FAQ.md Q038 (also Q035, Q036, Q002). PG = rulebook extracts/text-RB-players-guide.txt.

## R1 — Initiation learns all unknown Circle-1 DTs at Rank 1, simultaneously; start at Circle 1
- **Status:** ANSWERED
- **Ruling:** Every First-Circle Discipline Talent not already known, each at Rank 1, paid together from current LP (all or nothing). Known talents are skipped.
- **Sources:** Q038; PG:17278-17280, 17294-17314 (p.456)
- **Decision:** none
- **Used by:** T1, T2

## R2 — Rank-1 Legend price: New Discipline Talent Cost Table
- **Status:** ANSWERED
- **Ruling:** Row = lowest Circle among current Disciplines BEFORE adding the new one; column = ordinal (2nd/3rd/4th+). Existing `legend.json costs.newDisciplineRank1`. Each unknown DT at that price.
- **Sources:** Q038; PG:17282-17283, 17361-17372
- **Decision:** none
- **Used by:** T1, T2

## R3 — Silver fee
- **Status:** ANSWERED
- **Ruling:** 100 sp x (SUM of Circles in other Disciplines) x talents learned. Negotiable.
- **Sources:** Q038; PG:17261-17264, 17305-17315
- **Decision:** Owner (2026-11-21): editable pre-filled default deducted from purse with change; refused if unaffordable.
- **Used by:** T1, T2

## R4 — Circle-1 Talent Option at initiation
- **Status:** NOT-COVERED (price/fee inclusion); the slot itself ANSWERED
- **Ruling:** Book: option slots come from the new Discipline's own options; slot may be left open ("can be learned at a later time"); no explicit table for the option's Rank-1 price.
- **Sources:** Q038; PG:17284-17288
- **Decision:** Owner (2026-11-21): priced at the same Rank-1 table price as a DT; counts toward the fee talent count if picked in the modal; skipping costs nothing; later fill uses the existing option flow.
- **Used by:** T1, T2

## R5 — Prerequisites (tutor Circle 5+, 40 h/talent, GM discretion)
- **Status:** ANSWERED (book); not enforced
- **Ruling:** Book requires a tutor of the new Discipline at Circle 5+, 40 hours/talent, GM discretion.
- **Sources:** Q038; PG:17248-17293
- **Decision:** Owner (2026-11-21): non-goal, GM territory (as for Circle training).
- **Used by:** non-goals

## R6 — Known talents / shared DTs / Thread Weaving variants
- **Status:** ANSWERED
- **Ruling:** Known talents skipped; Thread Weaving (X) is a distinct talent per Discipline and must be learned; Karma Ritual/Durability are universal, not re-bought (inference). A known option becoming a DT (frees its slot) is out of scope.
- **Sources:** Q038; PG:17294-17314, 17349-17350, 17355-17360
- **Decision:** converting option -> DT = non-goal (owner, 2026-11-21)
- **Used by:** T1

## R7 — Derived effects of the new Circle 1
- **Status:** ANSWERED
- **Ruling:** Durability = highest across Disciplines; Defense bonuses do not stack; free talents rank = that Discipline's Circle (Q036). Already derived by the engine; no new storage.
- **Sources:** Q038, Q036; PG:17408-17423
- **Decision:** none
- **Used by:** T1 (verification only)
