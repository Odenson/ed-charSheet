# Rules brief: Update Shadow Meld (update-shadow-meld)

## R1 — Shadow Meld base text (PG p. 321)
- **Status:** ANSWERED, APP-DIFFERS
- **Ruling:** Circle 1 Nethermancer; 1 thread; weaving 5 / reattune 10; cast vs TMD; Touch; Rank minutes. Target gains +4 to all Stealthy Stride tests *while near shadows*, and may use Stealthy Stride as a default skill. Light does not end the spell; target is near-invisible again on stepping back into shadow.
- **Sources:** RULES-FAQ Q028; text-RB-players-guide.txt:12036-12049 (p. 321); text-spell-players.txt:2580-2597; text-spell-table-all.txt:308
- **Decision:** Owner 2026-10-05 (original request: "review the rulebook and update the spell accordingly"): follow the book (PG p. 321).
- **Used by:** T1
