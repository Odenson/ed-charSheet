# Rules brief: skill-model

## R1 — Knowledge/Artisan subject is player-named, GM-approved
- **Status:** ANSWERED
- **Ruling:** Player defines the subject; GM approval (GM-adjudicated, not tracked in app).
- **Sources:** RULES-FAQ Q043; PG:7184-7201, 7000-7002
- **Decision:** none
- **Used by:** T1, T2

## R2 — Tier and Rank-1 cost
- **Status:** ANSWERED
- **Ruling:** Knowledge and Artisan are Novice; new skill at Rank 1 = 200 LP (Novice) / 300 LP (Journeyman), 1 week, 10 sp fee.
- **Sources:** Q043; PG:17045-17102
- **Decision:** none
- **Used by:** T2

## R3 — Languages are individual named languages
- **Status:** ANSWERED
- **Ruling:** Speak/Read-Write Language are per-language catalog entries, Novice, same cost; not free-text.
- **Sources:** Q043; SC:340-352
- **Decision:** none
- **Used by:** T1

## R4 — Multiple Knowledge skills allowed
- **Status:** ANSWERED
- **Ruling:** Several subjects allowed; no cap printed.
- **Sources:** Q043; PG:7187-7190
- **Decision:** none
- **Used by:** T1
